# Release V2026.05 - May 2026

## Administrative Foundations & User Management

### Changed

- **User Management Restructuring**: Complete overhaul of the user management interface. Transitioned from a tab-based navigation to a dedicated page architecture (Users, Invitations, Roles), aligning the user experience with the "Overview" page navigation model.

---

## Survey Lifecycle & Advanced Exports

### Added

- **Intelligent Tabular Export**: New Excel and CSV export options allowing users to choose between technical names or multi-language labels, featuring automatic group prefix cleaning.
- **Structured Multimedia Export (ZIP)**: Implementation of a structured ZIP export system where media files are automatically renamed (format `question_index`) and organized into folders corresponding to data sheets (main and repeats).
- **GIS Export (Shapefile)**: Ability to export georeferenced data directly in Shapefile (.shp) format for immediate integration into professional SIG software like QGIS or ArcGIS.
- **Asynchronous Export Processing**: Integration of a background job system to handle large-scale data and multimedia exports, preventing browser timeouts and improving platform stability


---

## GIS & Spatial Analysis

### Added

- **Interactive Map View**: A new visualization mode allowing point, trace, and shape data from submissions to be displayed on an interactive map.
- **Dynamic Layer Management**: Spatial filtering system to toggle data layers based on the survey's geographic questions.
