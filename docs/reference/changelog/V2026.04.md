# Release V2026.04 - April 2026

## Administrative Foundations & User Management

### Added

- **Invitation List**: New list of sent invitations with the ability to filter by status (pending, accepted, and expired).
- **Dashboard (Statistics)**: Real-time statistics displaying the total number of users (all, active, administrators) on the platform, as well as ongoing invitations.
- **Personal Information**: External users can now update their personal information as well as their password.

### Changed

- **Roles Overview**: Updated the "Roles Overview" section to reflect the organization of roles and permissions across the platform.
- **UX**: Modified the behavior of the breadcrumb navigation.

---

## Infrastructure & Containerization

### Added

- **Enketo Server**: Installation and configuration of the Enketo server.

---

## Survey Lifecycle & Dashboards

### Added

- **Form Overview Page**: Creation of the Overview page for a form.
- **Submissions Datatable**: Implementation of a datatable to handle large submission datasets, with a panel to visualize nested repeats.
- **KPIs & Monitoring**: Added an interface displaying the total number of submissions and a daily progress chart on the dashboard to track field activity.
- **Tabular Consultation**: Visualization of all submissions in an interactive table (search, filters) to validate data quality.
