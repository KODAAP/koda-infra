# Release V2026.03 - March 2026

## Administrative Foundations & User Management

### Added

- **User & Permission Management**:
  - **Centralized User List**: New "Users list" page for Admins with filtering/sorting and project affiliation popup.
  - **Bulk Invitations & Revocation**: Support for individual/bulk invitations via email and access revocation at platform or project level.
  - **Web Users Page**: Dedicated page for inviting web users without project-level access.
  - **Project Role Management**: Ability to switch project roles (User/Project Manager) via  menus.
- **UX: Login & Profile**:
  - **Forgot Password Flow**: "Mot de passe oublié" button on login page and password setup via email invitation link.
- **Survey & Form Management**:
  - **Update Button**: Quick action button on the "Form versions" page.

### Changed

- **Navigation & UI**:
  - Sidebar "User" menu now stays open (down) by default.
  - Renamed **"Form Access Matrix"** to **"Form Access"**.
  - Renamed **"Form management"** page to **"Form versions"**.
- **Automated Lifecycle**: Removed "Ready to publish" section; form publication is now automatic after import.

### Removed

- **Scope Reduction**: Removed the generic **"Settings"** and **"Project Dashboard"** pages to focus on core survey management.

## Survey Lifecycle & Dashboards

### Added

- **Survey Dashboard**:
  - Dedicated view for survey management; clicking a survey now redirects here instead of the web link.
  - **Web Forms**: Public links renamed and auto-generated (Single/Multiple submission types).
- **Project Visibility**:
  - Visual highlighting (alerts/colors) for archived projects or those without an active Project Manager.
- **Safety & Notifications**:
  - **Remove Survey**: New deletion option with security/verification messaging.
  - **Admin Notifications**: Alerts when Insuco emails are revoked or external users deleted.
  - **Contact Support**: Support button added to the login page.

### Changed

- **Permissions**: Restricted project deletion capability to Administrators only.
- **Automated Form Lifecycle**: Enhanced update experience with questionnaire ID verification and automatic versioning.

### Removed

- **Cleanup**: Removed the **"Data"** page as part of the application scope reduction.
